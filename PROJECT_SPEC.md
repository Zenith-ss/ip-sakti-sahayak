# IP-SAKTI Sahayak - SIH Prototype Specification

## Overview
IP-SAKTI Sahayak is an AI-powered Ayurveda Intellectual Property (IP), Regulatory & Knowledge Assistant prototype for Indian government & health-tech innovation.

## Scope for Current Phase: Frontend Foundation Only
- Pure frontend prototype built using Next.js (App Router), TypeScript, Tailwind CSS, and Lucide Icons.
- No backend, AI/Gemini, database, auth, or RAG functionality yet.

## Application Structure & Routes
1. `/` - Homepage/dashboard
2. `/ip-assistant` - IP & Regulatory AI Assistant
3. `/medicine-checker` - Ayurveda Medicine Safety & Information Checker
4. `/patient-assistant` - AI Patient Consultation
5. `/doctor-report` - Doctor/Patient Consultation Summary
6. `/sources` - Authoritative Knowledge Sources
7. `/about` - About IP-SAKTI Sahayak

## Global Layout Requirements
- Left sidebar on desktop, collapsible responsive menu on mobile
- Top header with IP-SAKTI branding, India/International jurisdiction selector, language selector, and user profile placeholder
- Sidebar navigation: Dashboard, IP Assistant, Medicine Checker, Patient Assistant, Doctor Reports, Sources, About

## Design & Aesthetics
- White/light background, subtle green/blue accents (Ayurveda emerald + legal navy)
- Professional Indian government / health-tech aesthetic
- Cards with clean hierarchy, badges, and prominent disclaimer notices
